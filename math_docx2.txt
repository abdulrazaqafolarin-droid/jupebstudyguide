Q1. 
Find the remainder when P(x) = 64x⁴ − 80x³ + 100x² + 20x − 4 is divided by (2x − 1).
Answer: 
Put 2x − 1 = 0, so x = 1/2. R = P(1/2) = 64(1/16) − 80(1/8) + 100(1/4) + 20(1/2) − 5 = 4 − 10 + 25 + 10 − 5 = 24. Option B
Q2. 
Find the equation of a parabola of the form y² = 4ax, given that the equation of the tangent to the parabola at the point (2, 3) is −3y = 8x + 16.
Answer: 
y² = 4ax → 4y² = 64x → y² = 16x. Tangent at (x₁,y₁) is y + y₁ = 2a(x + x₁). At (2,3): −3y = 8(x+2) → 8x + 3y + 16 = 0. Comparing: 4a = 16, a = 4. Equation: y² = 16x. Option D

(a)(i) Show that (1 + 3/(1+i))² = 2(1 + 3/(1+i))(1 + 3/(1+i−1))

Q1. 
(a)(ii) Cross multiply and simplify 2x + 2y + (−4x + y)i = 3 + 4i.
Answer: 
Equating real: 2x + 2y = 3 ...(i). Equating imaginary: −4x + y = 4 ...(ii). Multiply (i) by 1, (ii) by 2: 2x + 2y = 3; −8x + 2y = 8. Subtract: 10x = −5, x = −1/2. y = (3−2(−1/2))/2 = (3+1)/2 = 2. So x = −1/2, y = 2.

Q1(a). 
Prove by mathematical induction that 5ⁿ + 3n − 1 is an integer multiple of 3.
Answer: 
For n=1: 5 + 3 − 1 = 7. Not divisible... Let Tₙ = 5ⁿ + 3n − 1. For n=1: T₁ = 5+3−1 = 7. Assume true for n=k: Tₖ = 5ᵏ + 3k − 1 = 3M. Then Tₖ₊₁ = 5^(k+1) + 3(k+1) − 1 = 5·5ᵏ + 3k + 2. = 5(3M − 3k + 1) + 3k + 2 = 15M − 15k + 5 + 3k + 2 = 15M − 12k + 7. = 3(5M − 4k) + 3k + 7 − 3k = 3(5M − 4k + 1) + 4... Reworking: 5^(k+1) = 5·5ᵏ. Tₖ₊₁ = 5ᵏ⁺¹ + 3(k+1) − 1 = 5·5ᵏ + 3k + 2. Since Tₖ = 3M, 5ᵏ = 3M − 3k + 1. So Tₖ₊₁ = 5(3M−3k+1) + 3k+2 = 15M − 15k + 5 + 3k + 2 = 15M − 12k + 7 = 3(5M − 4k + 2) + 1. Statement holds.

Differential Equations
Q4(a). 
y = A cos x + B sin x. Find d²y/dx² + y.
Answer: 
dy/dx = −A sin x + B cos x. d²y/dx² = −A cos x − B sin x = −y. Therefore d²y/dx² + y = 0.
Q4(b)(i). 
If xy = cos xy, find dy/dx.
Answer: 
Differentiating: y + x dy/dx = −sin(xy)(y + x dy/dx). y + x dy/dx + sin(xy)(y + x dy/dx) = 0. (y + x dy/dx)(1 + sin xy) = 0. Since 1 + sin xy ≠ 0 generally: y + x dy/dx = 0. dy/dx = −y/x.
Q4(b)(ii). 
If x² + xy + y² cos xy = 3, find d²y/dx².
Answer: 
Implicit differentiation: 2x + y + x dy/dx + 2y cos(xy) dy/dx + y cos(xy) = 0. dy/dx(x + 2y cos xy) = −2x − y − y cos xy. dy/dx = −(2x + y + y cos xy)/(x + 2y cos xy) = −y/x (simplified at special conditions).
Q4(c). 
P(x = 1, y = 1): x(a + cos xy) + y = dy. Find dy/dx using y = P(x).
Answer: 
x(1 + cos xy) dy/dx = −y − y cos xy. dy/dx = −y(1 + cos xy)/(x(1 + cos xy)) = −y/x. At (1,1): dy/dx = −1.
