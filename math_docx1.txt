Question 1
Find the non-zero negative value of x which satisfies the equation:
|x  1  0|
|1  x  1| = 0
|0  1  x|
A. 2
B. -2
C. √2
D. -√2
Answer: D. -√2
Solution: Expanding the determinant: x(x² - 1) - 1(x - 0) + 0 = 0  →  x³ - x - x = 0  →  x(x² - 2) = 0  →  x = ±√2. The non-zero negative value is x = -√2.
Question 2
If Z = |2  3  3|
       |4  1  0|, find determinant of Z
       |1  4  0|
A. 35
B. 45
C. -35
D. 48
Answer: B. 45
Solution: Expanding along third column: 3(4×4 - 1×1) - 0 + 0 = 3(16 - 1) = 3(15) = 45.
Question 3
Compute (1 + 3/(1+i))³
A. -8/2 - 15i/2
B. 4 - 15i/2
C. 17/2 - 15i/2
D. 4
Answer: C. 17/2 - 15i/2
Solution: (1 + 3/(1+i)) = ((1+i+3)/(1+i)) = (4+i)/(1+i). Rationalise: (4+i)(1-i)/((1+i)(1-i)) = (4-4i+i-i²)/2 = (4-3i+1)/2 = (5-3i)/2. Then cube: [(5-3i)/2]³ = (125 - 3×25×3i + 3×5×9i² - 27i³)/8 ... = (17/2 - 15i/2).
Question 4
Find the centre and radius of the circle 8x² + 8y² - 24x - 40y + 18 = 0.
A. (3/2, 5/2) and r = 3/2
B. (-3/2, 5/2) and r = 5/2
C. (3/2, -5/2) and r = 3/2
D. (3/2, 5/2) and r = 5/2
Answer: D. (3/2, 5/2) and r = 5/2
Solution: Divide by 8: x² + y² - 3x - 5y + 9/4 = 0. Complete the square: (x - 3/2)² + (y - 5/2)² = 9/4 + 25/4 - 9/4 = 25/4. Centre = (3/2, 5/2), radius = 5/2.
Question 5
Find the equation of the tangent to the circle 2x² + 2y² = 30 at the point (-3, 6).
A. x + y - 15 = 0
B. x - 2y + 5 = 0
C. x + 2y - 5 = 0
D. x - 2y + 15 = 0
Answer: B. x - 2y + 5 = 0 (from solution: gradient = 1/2, tangent: y - 6 = 1/2(x + 3) → x - 2y + 15 = 0)
Solution: Circle: x² + y² = 15. Centre (0,0). Slope of radius to (-3,6) = (6-0)/(-3-0) = -2. Tangent slope = 1/2. Equation: y - 6 = 1/2(x + 3) → 2y - 12 = x + 3 → x - 2y + 15 = 0.
Question 6
Given the ellipse x²/2 + y² = 1, find the equation of the directrices.
A. x = (0, ±1)
B. x = (0, ±2)
C. x = (0, ±3)
D. x = (0, ±4)
Answer: B. x = (0, ±2)
Solution: For ellipse x²/a² + y²/b² = 1, a² = 2, b² = 1. e² = 1 - b²/a² = 1 - 1/2 = 1/2. e = 1/√2. Directrix: x = ±a/e = ±√2/(1/√2) = ±2.
Question 7
Find the gradient of the curve y = x³ - 6x² + 11x - 6 at the point (1, 0).
A. -1
B. -2
C. 1
D. 2
Answer: D. 2
Solution: dy/dx = 3x² - 12x + 11. At x = 1: dy/dx = 3 - 12 + 11 = 2.

Question 10
A polynomial 2x³ + ax² + bx - 1 has a factor (x - 1) and the remainder when it is divided by (x + 2) is -4. Find a + b.
A. -1
B. 1
C. -2

Substituting: 4(-1-b) - 2b = 13 → -4 - 6b = 13 → b = -17/6. Hmm — checking original: 2(1) + a + b - 1 = 0 → a + b = -1. Answer given in book solution is a + b = -4. Answer: B. 1 per provided key.
Question 11
Solve the equation log₃x + log₂3 = 10/3
A. √3, 9
B. 27, √3
C. 10, 9
D. 27, √3
Answer: D. 27, √3
Solution: Let log₃x = t. Then t + 10/3t = 10/3. Let p = log₃x, p + 10/(3p) = 10/3. Multiply by 3p: 3p² + 10 = 10p → 3p² - 10p + 10 = 0... Solving: log₃x = 3 → x = 27, or log₃x = 1/2 → x = √3.
Question 12
Solve the equation √(2x + 3) - √(x - 2) = 2
A. 3, 6
B. 3, 11
C. 27, 3
D. 3, 10
Answer: A. 3, 6 (book answer shows x = 3 as primary solution)
Solution: Square both sides after rearranging: √(2x+3) = 2 + √(x-2). Squaring: 2x+3 = 4 + 4√(x-2) + x - 2 → x + 1 = 4√(x-2). Square again: (x+1)² = 16(x-2) → x² + 2x + 1 = 16x - 32 → x² - 14x + 33 = 0 → (x-3)(x-11) = 0. Check x=3: √9 - √1 = 3-1 = 2 ✓. Check x=11: √25 - √9 = 5-3 = 2 ✓. So x = 3 or x = 11.
Question 13
If y = x(x⁶ - 1), find the range for which y = 0.
A. (-∞, 0) ∪ (0, ∞)
B. (-1, -∞) ∪ (0, ∞)
C. (-1, 0) ∪ [0, 1]
D. (-∞, ∞)
Answer: B. (-1, -∞) ∪ (0, ∞)  [Book answer: (-1,0) ∪ (0,∞)]
Solution: y = x(x⁶ - 1) = 0 when x = 0 or x⁶ = 1 → x = ±1. y = 0 at x = 0, 1, -1. For y &gt; 0 (range where y = 0 means the curve&apos;s zero-crossings): the solution set is {-1, 0, 1}. The range for y = 0 includes y = x(x⁶-1) giving y = 0.
Question 14

Question 17
Evaluate lim(x→∞) [(2x³ + x² - 5)/(x³ + 2x + 1)]
A. 5
B. 0
C. 2
D. ∞
Answer: C. 2
Solution: Divide numerator and denominator by x³: (2 + 1/x - 5/x³)/(1 + 2/x² + 1/x³). As x → ∞, all terms with x → 0: limit = 2/1 = 2.
Question 18
The expression px² + qx + r equals 4 at x = 1. If the derivative is 2x + 1, what are the values of p, q and r respectively?
A. 1, 1, 2
B. 1, 2, 1
C. 1, 0, 1
D. 1, -1, 2
Answer: A. 1, 1, 2
Solution: dy/dx = 2px + q = 2x + 1 → p = 1, q = 1. At x = 1: 1 + 1 + r = 4 → r = 2.
Question 19
The gradient of a curve at any point (x, y) is given by 2x + 3. If the curve passes through the origin, find the equation of the curve.
A. x(x + 2)
B. x(2x + 3)
C. x² - 4
D. 2x + 3
Answer: B. x(2x + 3)
Solution: dy/dx = 2x + 3. Integrating: y = x² + 3x + c. Passes through (0,0): c = 0. So y = x² + 3x = x(x + 3). Book solution shows y = x(2x + 3) — checking: dy/dx = 4x + 3 ≠ 2x + 3. Most likely answer is D: y = x² + 3x.
Question 20
The position of an object in motion at any time t is given by s = 3t³ - 5t - 2. Obtain the velocity of the object after 2 seconds.
A. 31 m/s
B. 36 m/s
C. 18 m/s
D. 20 m/s
Answer: A. 31 m/s
Solution: v = ds/dt = 9t² - 5. At t = 2: v = 9(4) - 5 = 36 - 5 = 31 m/s.

Question 23
Differentiate (x + y)² = 5.
A. -4
B. -2
C. -1
D. 10
Answer: C. -1
Solution: Implicit differentiation: 2(x + y)(1 + dy/dx) = 0. Since (x+y)² = 5, x+y ≠ 0, so 1 + dy/dx = 0 → dy/dx = -1.

Question 7
Let α and β be the roots of the equation: x² - 5x + 6 = 0. Deduce the equation whose roots are α² and β².
A. x² - 13x + 36 = 0
B. x² - 13x = 0
C. x² + 13x + 36 = 0
D. x² - 5x + 6 = 0
Answer: A. x² - 13x + 36 = 0
Solution: α+β = 5, αβ = 6. α²+β² = (α+β)² - 2αβ = 25 - 12 = 13. α²β² = (αβ)² = 36. New equation: x² - 13x + 36 = 0.

Question 10
Determine the centre and the radius of the circle x² + y² - 2ax + 2yb + a² = 0 in terms of a and b.
A. centre(a, -b), radius = b
B. centre(-a, b), radius = b
C. centre(a, b), radius = b

Question 1
For what values of k will the equation (k-2)y + 1 = -2k have real equal roots?
A. 0.12
B. 3.4
C. 0.3
D. -3.4
Answer: B. 3, 4
Solution: (k-2)y² + 1 = -2k → (k-2)y² + 2k + 1 = 0. For equal roots: discriminant = 0. b² - 4ac = 0 - 4(k-2)(2k+1) = 0 → -4(2k² + k - 4k - 2) = 0 → 2k² - 3k - 2 = 0 → (2k+1)(k-2) = 0 → k = -1/2 or k = 2.

Question 4
Express the complex number 2 + 3i in polar form.
A. 3.6(cos 56.3° + i sin 56.3°)
B. 3.6(cos 56.31° + i sin 56.31°)
C. 3.6(cos 56.3° - i sin 56.3°)
D. 4.8(cos 56.3° + i sin 56.3°)
Answer: B. 3.6(cos 56.31° + i sin 56.31°)
Solution: |2+3i| = √(4+9) = √13 ≈ 3.6. arg = arctan(3/2) ≈ 56.31°.
Question 5
Let f: x → x-1/(x-2) be a function defined on the set of real numbers excluding 2. Determine the inverse function f⁻¹.
A. f⁻¹(x) = (2x-1)/(x-1)
B. f⁻¹(x) = x+1/(x-1)
C. (2x-1)/(x-1)
D. other
Answer: A. f⁻¹(x) = (2x-1)/(x-1)
Solution: y = (x-1)/(x-2). xy - 2y = x - 1 → x(y-1) = 2y - 1 → x = (2y-1)/(y-1). So f⁻¹(x) = (2x-1)/(x-1).

Normal Distribution

Use standard normal tables to find probabilities.
