Q1: If P = {x: 3 < x < 15, x is prime} and Q = {x : 2 < x < 14, x is odd}, evaluate n(P $∩$ Q) + n(P $∪$ Q)
  A: 35
  B: 26
  C: 12
  D: 10
  Correct: D

Q2: Determine the range of values of x for which $-2x²$ + 5x + 3 > 0
  A: -3 < x < $½$
  B: -2 < x < 3
  C: $½$ < x < 2
  D: -1/2 < x < 3
  Correct: D

Q3: The following binary operations are commutative with the exception of
  A: a * b = a + b – 3ab
  B: a * b = 5/a + 5/b
  C: a * b = a – b + 3ab
  D: a * b = 2a + 2b – ab
